# AgentTxn v0.5.0：安装与下载

## 从这里开始 / Start here

AgentTxn 为 AI Agent 的外部写入提供审批、审计、Saga 补偿与未知结果核对。Python 3.11+；默认 SQLite，可选 PostgreSQL SDK 后端。

- **首次体验 / Try it:** 下载[命名源码包](https://github.com/valseeee/agenttxn/releases/download/v0.5.0/agenttxn-v0.5.0-source.zip)，按[当前快速启动](https://github.com/valseeee/agenttxn#首次体验运行离线示例)运行离线成功与补偿示例。预期分别为 `COMMITTED` 和 `COMPENSATED`，审计验证均为 `True`。无需 Token 或外部 API。
- **项目集成 / Install:** 在 Python 3.11+ 虚拟环境中安装本次 wheel：

```bash
python -m pip install "https://github.com/valseeee/agenttxn/releases/download/v0.5.0/agenttxn-0.5.0-py3-none-any.whl"
agenttxn version
```

版本应显示 `0.5.0`。wheel 安装 SDK 和 CLI；示例需另下载源码包。Windows 未激活虚拟环境时可使用 `.venv\Scripts\agenttxn.exe`，Linux/macOS 使用 `.venv/bin/agenttxn`。

可选 PostgreSQL / Optional PostgreSQL SDK dependency：

```bash
python -m pip install "agenttxn[postgres] @ https://github.com/valseeee/agenttxn/releases/download/v0.5.0/agenttxn-0.5.0-py3-none-any.whl"
```

通过 `Engine.open_postgres(dsn, ...)` 使用；CLI 当前仍使用 SQLite。配置见[运维文档](https://github.com/valseeee/agenttxn/blob/v0.5.0/docs/operations.md)。
